# FieldToFit · A「全景聚焦」精修素材包

2026-09-10 · 第一版矢量精修，保留用户选定的 A 方案。本素材包已用于 FieldToFit v1.0.0 的网站和项目展示。

## 先看哪里

- `index.html`：可离线打开的中文预览、原稿对比、大小尺寸与裁切测试、下载入口。
- `preview.png` / `preview.svg`：完整展示板。
- `svg/`：正式矢量输出，图形与字标都是路径或矩形，没有内嵌位图、外部字体或远程资源。
- `png/`：透明图形、横排／竖排组合、深浅底组合的高清 PNG。
- `icons/`：应用图标、浏览器图标与 ICO。
- `source/`：可编辑几何母版、微型母版、字标使用的字体及可重复生成脚本。
- `qa/validation.json`：自动校验结果。

## 改善了什么

1. **保留 A 的轮廓与叙事。** 左侧四个方块是分散的资料；阶梯式 F 框架组织资料；右侧两个方块是整理后的材料。没有把主标换成其他构形。
2. **统一几何关系。** 标志基于 8 单位网格，六个资料方块均为 24 × 24；主要相邻间距为 8。右侧原先大小、位置略不一致的方块已经对齐。
3. **理顺内部留白。** 阶梯转折和中段宽度经过重绘，避免原始生成图中不稳定的边缘和狭窄缝隙。
4. **重制字标。** 使用 Rubik Bold 的几何无衬线字形，方形 i 点呼应资料方块；正式输出已转曲，拼写为 `FieldToFit`，不依赖观看者安装字体。
5. **独立微型版。** 在 16–32 px 版本中去掉 F 内部阶梯、合并右侧两个方块为短横，保留左侧四块。微型图形是光学校正版，不是主标直接缩小。16 px 的边界落在整数像素上。

## 尺寸、留白与配色

- 主图形紧边界为 **160 × 112**，不改变长宽比。
- 标准图形建议可见宽度 **≥ 48 px**；单独主标文件带留白，完整图片显示宽度建议 **≥ 64 px**。16–32 px 位置使用微型版，不用竖排组合。
- 横排组合建议显示宽度 **≥ 240 px**；再小则切换到独立图形。竖排组合建议宽度 **≥ 200 px**。这些是本版视觉检查得到的建议，并非平台强制规则。
- 图形周围最小安全留白为 **24 单位**，即一个资料方块边长。生产文件已包含基础边距；不要将其他图形贴进留白。
- 默认浅底：**#FAFBF8**；默认深色：**#151917**。本轮不另引入鲜艳强调色。
- 不拉伸、不描边、不加投影或渐变；深底换暖白／纯白图形，不把深色图形直接放上去。
- 应用图标的图形位于中心安全区域，可适应圆角或圆形裁切。预览页里的圆角是展示效果，原始 PNG 保留方形满底。

## 字体来源与权利边界

字标使用 **Rubik Bold**，字体项目为 [Rubik](https://github.com/googlefonts/rubik)，采用 [SIL Open Font License 1.1](https://raw.githubusercontent.com/google/fonts/main/ofl/rubik/OFL.txt)。随包保留 `source/Rubik-Bold.ttf` 与 `source/Rubik-OFL.txt`，以便重建字标。正式标志 SVG 本身不需要安装该字体。

主图形是对用户选定 AI 生成概念的几何重绘。此包没有完成图形商标近似检索，不代表取得商标注册或独占权。本次没有替用户新增整个品牌素材的对外授权条款；公开分发策略可在正式品牌发布时单独确定。

## 可重复生成

生成脚本只写本素材包，不会修改项目应用文件。需要 Node.js 及 `sharp`、`@napi-rs/canvas`、`jszip`。

```sh
node source/build.cjs
```

如果依赖不在常规搜索路径，用 `NODE_PATH` 指向依赖目录。也可传入另一份合法取得的 Rubik Bold 字体路径；字体版本变化可能影响字标，正式发布应使用本包字体或直接使用已转曲的 SVG。
