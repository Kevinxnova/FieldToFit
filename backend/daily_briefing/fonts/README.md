# PDF typeface

Noto Sans SC is redistributed under the SIL Open Font License in [OFL.txt](OFL.txt).
Upstream: [Google Fonts / Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc).

`NotoSansSC.ttf` is a static weight-450 instance of the upstream variable TTF, made with fontTools 4.66.1. It includes the original full character coverage; PDF generation subsets only the glyphs used by the edition. No system fonts are required at runtime.
