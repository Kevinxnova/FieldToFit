# v1.1.0-beta.1 · AI 知识工作台与仓库整理

日期：2026-09-07。**开发候选版，尚未创建公开 Release 或合并到 main。** 当前开发分支为 `codex/metis-knowledge-workspace`，供审阅和本地试用。

## 升级与后续重点

保留 `.env`、数据库、日志、平台配置和本机依赖。本次没有迁移或合并根目录与 `data/` 下的数据库。静态构建通过后，按 [部署指南](../guides/deployment.md) 在隔离环境检查，核对实际浏览地址的 `ALLOWED_ORIGINS`，再安排正式升级。
