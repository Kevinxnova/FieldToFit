# FieldToFit v1.0.4

2026-09-11 · 社区、开发者投稿与阅读导航。

## 变化

- REQ-Y-04：目录默认两级，数量右对齐；标题定位和箭头分开，一次只展开一组明细；手机采用当前章节按钮与底部抽屉。
- REQ-AB-01：保留原品牌开头，重组两种使用方式、收录范围、维护、社区邀请与版本链接。
- REQ-C-01：新增独立社区页、三个参与入口和六项投稿表单；支持用户自行发送 GitHub Issue / 邮件。社区在关于页下方，“我的账户”菜单移除，兼容路由保留。
- 已审投稿复用持续关注资料；HTTP / curated_watch 增加可选 origin 过滤，网页和 AI 共用项目材料。工具数仍为 12；没有真实投稿时显示为空。
- 当前需求为 21 个父项、85 个子项；真实投稿审核和连续运营保持待执行。

## 发布边界

本次是既有页面、资料读取和提交渠道的补丁更新，不新增账户、论坛或独立投稿数据库，使用 v1.0.4。没有修改五类 27 主体、10 条动态或 190 个图表点，也没有发送测试投稿。

## 验证与部署

本地构建与 208 项后端测试通过（1 项跳过）。桌面/手机浏览器通过表单草稿、目录交互、关于页、空项目展示和 HTTP 过滤检查。正式站点、MCP 同源读取和线上浏览器验收也已通过。部署与标签信息以[验收记录](../validation/2026-09-11-v1.0.4.md)为准。
