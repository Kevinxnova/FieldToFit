## 本次发现并补充的配置说明

默认允许来源是开发页面 5173 端口。直接浏览后端提供的静态页面时，若未将实际端口加入 `ALLOWED_ORIGINS`，带 Origin 的对比请求会返回 403。部署指南已补齐该配置；按实际 8001 预览地址配置后，双资源对比及后台检查通过。对比接口要求 2–4 个不同资料 ID，空候选返回 400 符合现有接口契约。

## 复验入口

```bash
source .venv/bin/activate
PYTHON_DOTENV_DISABLED=1 TURSO_DATABASE_URL='' TURSO_AUTH_TOKEN='' pytest
python -m compileall -q backend api scripts tests
python scripts/maintenance/check_repository.py
python -m pip install --dry-run --no-index -r backend/requirements.txt
cd frontend
npm run build
```

按 [隔离启动指南](../../../guides/local-development.md) 建立临时数据，并按 [部署指南](../../../guides/deployment.md) 配置浏览地址。启动后依次打开上述路由，用临时管理密码检查两个后台的读取与退出。MCP 复验入口见 [examples](../../../../examples/README.md)，可用 `METIS_MCP_URL` 指定当前预览地址。
