## 复验方法

1. 按 README 建立环境，前端运行 `npm ci` 和 `npm run build`。
2. 使用独立的 `METIS_DATA_DIR`，从仓库根目录运行 `python -m examples.editorial.load`，无需模型密钥即可导入 6 个样本；这是明确的示例导入，不是后台默认写入。
3. 安装 `examples/validation/requirements.txt`，运行 `python -m examples.validation.run_suite --output /tmp/metis-runtime-results.json`。脚本只执行清单内代码，并检查安装版本与档案是否一致。
4. 启动后端，安装 `mcp>=2.1.1,<3`，运行 `python -m examples.validation.mcp_client /tmp/metis-mcp-results.json`。可用 `METIS_MCP_URL` 指定本地地址。
5. 日常流程运行 `python -m backend.knowledge.daily`，每 1 天由调度器调用；各处理阶段保留结果。Vercel 增加每日 `/api/cron/knowledge` 有界处理；超出单次额度的积压不会被标成全部完成。
6. 新知识库生成模型配置使用 `METIS_MODEL_*`；GPT 示例为 Responses 协议。凭证仅在服务器环境配置，Codex 对话登录不被当作 API 凭证。旧策展功能的生成配置仍属于旧流程。

模型接口说明依据 [OpenAI Responses](https://developers.openai.com/api/docs/guides/latest-model)；Turso 验收边界参照其 [HTTP 连接与事务说明](https://docs.turso.tech/sdk/http/reference)。容器实际构建、生产数据库验收、3 天运行观察、真实用户案例和基线对照仍需完成，不能用本表中的代码实现替代。
