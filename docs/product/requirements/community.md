## REQ-C-01 · 社区与开发者投稿

**为什么做：** 让真实开发成果更容易被发现、理解与采用，让愿意整理资料、测试和开发的人找到参与入口。

**方案与范围：** 新增社区页及六字段投稿草稿，使用 GitHub Issue / 邮件接收，人工审核后复用持续关注资料发布与 MCP。不新增账户、论坛或自动发布系统。

**依赖：** REQ-Y-02、REQ-Y-04、REQ-AB-01、REQ-O-01、REQ-AI-03。**父项状态：** 页面、投稿通道和读取已实现；首批真实投稿与每周处理记录待执行。
