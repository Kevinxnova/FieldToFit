# 热点信息卡三列自适应验收

日期：2026-10-12（Asia/Shanghai）。对应[REQ-6-22](../../FieldToFit-PM.md#hot-information-cards-plan)，源码批次v1.8.38。所有者要求一排三张、大小自适应；本批仅调整响应式样式与相关记录，没有正式部署或生产内容发布。

## 实现与范围

原规则在窗口小于1000px时强制单列，当前约882px窗口实际仍有约659px卡片区域。现改用容器查询：阅读区域至少600px时三列等宽、同排等高；不足600px时单列居中，单卡最大520px。卡片间距、留白、边框、图形和标题随实际卡宽调整，标题18–26px、正文13px；不截断内容，不设固定高度。

原镭射交互、详情入口、图片和数据不变，无新增依赖。全局目录在较宽窗口占据独立一栏，因此列数由阅读区域决定，并非随整个窗口宽度单调增加。

## 实际验证

使用应用内Chromium浏览器访问 `tests/browser/hot-cards_server.py` 提供的隔离SQLite预览。保持用户原110%缩放，调整视口后读取实际CSS像素；1024px目标实际测得1023px。分别检查中文和英文，共七种尺寸、14组组合。

| 实际窗口宽度 | 卡片区域宽度（约） | 列数 | 单卡宽度（约） |
| --- | --- | --- | --- |
| 1440px | 861px | 3 | 276px |
| 1200px | 709px | 3 | 227px |
| 1023px | 533px | 1 | 520px |
| 882px | 659px | 3 | 211px |
| 768px | 545px | 1 | 520px |
| 390px | 350px | 1 | 350px |
| 320px | 280px | 1 | 280px |

全部组合列数符合规则，页面无横向溢出，卡片内容无横向裁切；三列状态下三张卡片起点及高度一致。所有正文13px，标题均在18–26px内。人工查看当前窗口截图，确认三张卡片并列、内容完整，中文卡片约668px高。验证后恢复用户原窗口尺寸和中文显示。

- `npm --prefix frontend run build`：类型检查与生产构建通过，128个模块；仍有既有主包超过500kB提示。
- `release_metadata.py --write`已同步版本与双语摘要，无参数复核通过。`check_repository.py`：v1.8.38、152文档、1258本地链接、315相对导入、23主REQ／156子REQ，错误0；`git diff --check`通过。
- 原始14组测量值保存于忽略目录 `output/operations/hot-cards/layout/results.json`，当前窗口截图为同目录 `current-window.jpg`。
- 本批为CSS布局调整，未重复执行此前的后端及完整业务回归；历史动效与流程证据见[镭射样式验收](2026-10-12-hot-card-motion.md)。
