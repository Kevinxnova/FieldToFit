# 搜索可读页面与独立内容页验收

日期：2026-09-22。源码批次 v1.5.12，对应 REQ-18-1 至 4。用户授权开发，并明确现有介绍等文案不改写。正式站仍为此前已部署的 v1.5.11；本批未部署，未登录或提交搜索平台。

## 实现范围

- 五个公开主入口输出初始核心 HTML；28 条动态和 32 项持续关注各有稳定 `/news/D-…`、`/watch/CW-…` 网址，正文、解读、版本表、日期和出处读取既有公开 API/MCP 使用的同一发布集合。没有新增或改写发布内容。
- 五份中英文介绍、四组中英文主标题从原组件抽到共享 JSON，逐字核对与修改前源码相同；关于页原 FIELD → FIT 保留。浏览器使用原阅读／交接／访问计数组件，独立页默认展开进一步阅读；现有长页和旧锚点继续可用。
- 逐页 title／description／canonical／OG 在初始响应与客户端同步。新分享、内容标题、目录和相关入口采用独立网址；参数不生成新的 canonical。未新增虚构的结构化评分、作者或日期。
- 真实 robots 和自动 sitemap；当前隔离发布集合包含 5 个主入口 + 60 个内容 URL。`lastmod` 只取公开内容发生变化的发布历史时间；导入、草稿、私密字段和无变化发布不刷新。无可靠修改时间的种子或静态入口省略该字段。
- 新页面、归并跳转、公开详情读取和 sitemap 不缓存；下架后新请求不返回原正文，无效 ID 为 404，读取失败为 503，私密接口继续认证。管理／个人／兼容资料入口、错误和非搜索 API 不索引；预览及非正式域名有 noindex，预览 robots 禁止抓取。
- 前端构建复制当前资源哈希对应的 HTML 外壳到 Python 打包目录；Vercel 非 API 页由 Flask 处理，静态资源由部署输出提供。Docker 构建路径同步适配共享文案。没有生产迁移、新表、第三方追踪脚本或自动站长提交。

## 实际验证

1. 完整隔离回归：363 项通过、1 项跳过，25.98 秒；SQLite 临时库，禁用 dotenv，不连接生产凭据。之后补充归并缓存、兼容入口 noindex 及可读取的索引排除规则，最终 36 项相关回归通过，2.95 秒。
2. `tests/test_search_pages.py` 对全部公开详情逐项核对标题、介绍、解读、版本表、来源和公开修订；65 个 sitemap URL 与发布集合对账且全部可读。草稿保存／预览不泄露，发布／修改／下架立即反映；归并只跳转到公开目标。包括无变化发布日期、真实 404／503、故障脱敏、HTML 转义、预览规则与私密入口。
3. 新详情路径沿用访问会话：动态与持续关注详情在同一会话内只计一次，不存在条目不入统计；既有累计持久化、并发、隐私及清理回归继续通过。
4. 浏览器最终复验：40 个断言通过、页面错误 0。实际 Chrome／Playwright 检查无 JavaScript 的五个主入口、动态／资料正文和版本表；桌面 1440×1000、手机 390×844、英文深色模式；详情分享复制、旧 hash 展开、前进后退元数据、SPA 404 后清除正文和 noindex、手机无横向溢出。测试访问仅在隔离站点。
5. 前端 TypeScript／Vite 构建通过，88 模块。共享文案直接与修改前源码解析比对，通过。最终仓库检查：101 份文档、810 个本地链接、168 个相对导入、18 主 REQ／114 子 REQ、0 错误；`git diff --check` 通过。
6. Vercel 本地生产目标构建通过。首次直接在共享目录构建因缺少 uv 失败，临时安装 uv 后又遇到本地测试配置引起的 Python 锁文件不匹配；随后按正式上传排除规则，在无凭据临时目录、Python 3.12 构建成功。检查函数 `filePathMap` 中的新 Python 模块、共享 JSON、模板、生成外壳及既有统计 SQL／内容文件，外壳引用的资源均存在于静态产物；动态路由正确转入 Flask。生成的共享目录依赖输出和锁文件已清除，项目运行依赖未更改。

原始浏览器结果、桌面／手机截图、构建日志及打包检查结果保存在忽略目录 `output/acceptance/search/`。浏览器脚本为 `tests/browser/search.cjs`，隔离服务复用可配置端口的 `tests/browser/visits_server.py`。
