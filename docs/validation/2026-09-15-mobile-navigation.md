# 手机「更多」导航验收

日期：2026-09-15。源码版本 v1.3.3，REQ-6-17，关联 REQ-6-14。本地开发及正式站部署后验收已完成；正式站运行 v1.3.3。GitHub 开发分支与 main 已同步；本次未创建发布标签或 GitHub Release。

## 实现与边界

手机底部固定 For you、For your AI、更多。更多使用原生对话框，四行链接进入 `/about`、`/community`、`/sources`、`/admin`；打开时隔离背景焦点与滚动。面板内保留底部三个入口，支持直接切换主页面及再次点击关闭。四个辅助页面保持「更多」高亮。

新增面板与原手机目录通过展开事件互斥；两者滚动锁均根据实际对话框打开状态决定，避免交替打开时恢复错误。关闭返回按钮，跳转聚焦目标主内容。桌面维持原侧栏。管理页面和权限接口保持原实现，不新增私密信息查询。
