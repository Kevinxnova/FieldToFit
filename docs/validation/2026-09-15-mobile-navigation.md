# 手机「更多」导航验收

日期：2026-09-15。源码版本 v1.3.3，REQ-6-17，关联 REQ-6-14。范围为本地开发与验收；未推送、打标签或部署，正式站仍为 v1.3.2。

## 实现与边界

手机底部固定 For you、For your AI、更多。更多使用原生对话框，四行链接进入 `/about`、`/community`、`/sources`、`/admin`；打开时隔离背景焦点与滚动。面板内保留底部三个入口，支持直接切换主页面及再次点击关闭。四个辅助页面保持「更多」高亮。

新增面板与原手机目录通过展开事件互斥；两者滚动锁均根据实际对话框打开状态决定，避免交替打开时恢复错误。关闭返回按钮，跳转聚焦目标主内容。桌面维持原侧栏。管理页面和权限接口保持原实现，不新增私密信息查询。

## 实际检查结果

| 范围 | 结果与环境 |
| --- | --- |
| 前端构建 | TypeScript 与 Vite 构建通过 |
| 四个辅助入口 | 正确跳转；面板自动关闭；当前入口高亮，跳转后主内容获得焦点 |
| 关闭与历史导航 | 关闭按钮、再次点击更多、背景、Escape；前进/后退和刷新后状态通过 |
| 键盘 | Tab 在原生对话框内循环，Escape 后返回触发按钮；与目标主内容的焦点交接通过 |
| 目录互斥 | 页内目录与更多交替打开时最多一个对话框；收起后背景滚动恢复 |
| 手机布局 | Chromium 下 320×568、390×844、430×932、667×375；无横向溢出，面板与导航不重叠，矮屏内部可滚动到最后一项 |
| 语言和主题 | 中文浅色与英文深色通过；390px 截图人工检查通过 |
| 桌面 | 1440×1000 关闭手机面板并显示原侧栏 |
| 管理权限 | 隔离 SQLite 后台：匿名管理统计返回 401；未登录显示登录表单；用临时测试凭据登录后，从其他页面返回管理模块可用 |
| 页面错误 | 本轮浏览器自动化收集到 0 个 pageerror |
| 版本同步 | release_metadata 检查通过；相关单元测试 8 项通过 |

浏览器脚本：[mobile-navigation.cjs](../../tests/browser/mobile-navigation.cjs)。运行使用 `READING_BASE_URL` 指向本地前端，`READING_API_URL` 指向隔离后台；可选 `READING_ADMIN_PASSWORD` 只用于测试实例。通过 `PLAYWRIGHT_MODULE`、`READING_CHROMIUM` 指定本机运行时。本次使用新建临时数据库，不读写正式站数据库，不使用生产密码。

结果与截图保存在忽略目录 `output/validation/mobile-navigation/`，未将测试数据或凭据纳入版本库。旧目录浏览器检查同步改为核对计算后的滚动状态；旧 v1.0.4 全套脚本含历史版本和内容断言，本批未重跑该旧版本全套流程。
