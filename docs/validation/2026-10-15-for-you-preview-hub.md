## 同内容性能对照

同机、同脚本`tests/reading_benchmark.py`、同153条动态／50份档案种子；各一次冷读、五次热读。日报没有额外人工发布，确保前后基线一致；浏览器样刊数据另计。HTML包含服务端正文与随附读取数据，不含JS／CSS／图片资源。

| 指标 | 改动前 | 改动后 |
| --- | ---: | ---: |
| 首页HTML及内嵌数据 | 936,542 B | 122,617 B（−86.9%） |
| gzip估算 | 181,225 B | 27,761 B（−84.7%） |
| 冷读 | 173.38 ms | 171.98 ms |
| 热读中位 | 16.36 ms | 10.24 ms |
| 冷读SELECT／连接 | 15／7 | 15／7 |
| 热读SELECT／连接 | 7／2 | 7／2 |
| 初始额外公开内容请求 | 0 | 0 |

初始数据继续随正文提供，首页不追加完整图表／日志请求；浏览器本地请求记录与缓存测试相符。点击进入完整栏目才请求相应view；返回缓存内容同时校验修订。冷响应差异很小，查询数未减少；不能声称冷启动、生产TTFB或Web Vitals已改善。主要可确认收益是首页传输数据减少；原动效／图像资源及主JS包仍存在。
