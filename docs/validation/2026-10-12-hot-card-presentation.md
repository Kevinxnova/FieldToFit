# 热点信息卡转正放大验收

日期：2026-10-12（Asia/Shanghai）。对应[REQ-6-22](../../FieldToFit-PM.md#hot-information-cards-plan)，源码批次v1.8.39。所有者要求默认稍有旋转、鼠标移入时变成正面并放大。本批仅本地实现和验证，未部署或发布正式内容。

## 实现

- 三列默认错角陈列：X轴3°，Y轴−8°／5°／8°，Z轴−0.8°／0.6°／0.8°。加强卡边和投影，关键变化图形区由72–108px增加为96–140px。
- 鼠标移入时600ms转正、上浮8px并放大1.04倍；卡面保持正向，反光继续随指针移动。离开后回到原姿态。命中区域不随卡面变形，动画帧收敛后停止。
- 键盘聚焦时同样转正，聚焦期间保持正面，详情链接可直接操作。触屏、阅读区域不足600px、减少动态效果模式静态展示；内容不依赖悬停。
- 保留按阅读区域宽度决定的三列／单列布局。901–1100px窗口将首页目录收为按钮，修复中等窗口目录栏挤占三列的情况；目录抽屉与定位继续可用。
- 未改变内容、来源、日期、PNG、审核发布或数据库，无新增依赖。

## 实际验证

使用 `tests/browser/hot-cards_server.py` 的临时SQLite预览和本机Chrome无头浏览器，另在用户的应用内浏览器检查当前页面。地址为 `http://127.0.0.1:18062`，不连接生产数据库。

1. 更新已有 `tests/browser/hot-cards-motion.cjs`，以实际卡面变换验证交互。**85项检查通过，14张截图，页面脚本错误0**。覆盖中文／英文与浅／深色，默认倾斜、移入转正放大、光效随指针移动、离开恢复；动态效果偏好切换；键盘聚焦、Enter读详情、返回原位置。
2. 882px窗口三张卡片可分别悬停，始终只有对应卡片进入展示状态，无页面横向溢出；1024px保持三列，目录按钮打开后可以跳回信息卡并正确收起。
3. 1024／768／390／320px触屏模拟下，中英文卡面静态，链接至少44px高，无横向溢出，详情可达。320px重复长文案与待更正提示仍可阅读。
4. 首次执行中，长文案夹具未生效：新增882px测试后，后续导航到相同带锚点URL没有触发重新取数。为该夹具明确重新加载页面，再完整执行，85项通过；未将首次超时记为通过。
5. 应用内浏览器当前1016px窗口实际呈现三列，单卡约244px，默认3D变换已生效。人工查看当前页面、浅色正面放大截图，确认卡边、标题、条件区与相邻卡可辨认。测试截图中的固定导航及边缘取景属于截图范围，不是正文裁切。
6. `npm --prefix frontend run build`：类型检查与生产构建通过，128个模块。保留既有主包超过500kB提示。
7. `release_metadata.py --write`已同步双语README、前端版本和站内日志；`check_repository.py`核对v1.8.39、153文档、1265本地链接、315相对导入、23主REQ／156子REQ，错误0。`git diff --check`通过。

原始检查结果和截图保存在忽略目录 `output/operations/hot-cards/presentation/`，包括 `result.json`、`current-window.jpg` 和中英／主题／触屏截图。未重复执行后端和图片下载回归；此前记录见[镭射样式验收](2026-10-12-hot-card-motion.md)。
