# 日报九栏目与取材核验：本地验收

2026-10-18，所有者明确批准最终九栏目方案，以 minor **v1.12.0** 开发和验证。对应 [REQ-24-11](../../FieldToFit-PM.md#daily-nine-sections)。本记录为本地开发验收，不代表正式部署或今日新刊发布。

## 完成范围与兼容

统一顺序：今日重点 → AI公司 → 热点AI产品追踪 → AI芯片 → 具身智能 → 基础设施 → 监管政策 → 商业动态 → AI股市。

- 产品追踪独立栏目、独立锚点，保留本期变化与近期已核实版本；商业动态位于监管之后。网页、初始HTML、HTTP／MCP和双语PDF一致。
- 新稿通过可选 `layout_version=2` 采用九栏，公开数据增加 `section_order`；原协议名保持。历史七栏读取、正文哈希和已存PDF不改，无数据库迁移。
- 具身、基础设施和商业各三个必查主题，提供30个发现入口及按主题拆分的18条中英文查询。官方原文为核验依据，媒体用于发现和交叉核实；入口清单本身不是取材成功回执。
- 本地核验要求实际研究记录、原始事件日期及阶段、来源归属、产品发布日期及渠道；商业媒体消息要求两家独立原始出版者记录。扩展证据绑定复核哈希，复核由七项增加到九项。失败覆盖、旧事件、缺来源、未知状态、超长新闻窗口和不兼容生产版本均有阻断测试。
- 保留最近完整收盘、11维覆盖、七期去重及09:00规则。程序检查证据完整性；事实语义、转载关系和日期归属仍需GPT实际重开原文复核。

## 隔离环境与样刊

`tests/browser/daily-nine-server.py` 创建临时SQLite库，不读取 `.env`，关闭远程数据库和外部调用，监听 `http://127.0.0.1:18072`。浏览器禁用外部HTTPS请求。

验收页 `/for-you/daily/2026-10-14` 与英文对应页采用明确标注的**版式审阅样刊**：复用10月13日历史样刊，商业动态为显式测试文字。仅用于布局、链接、双语和下载验证，不是10月14日或10月18日真实新闻。另保留10月13日旧版式作为兼容对照。真实PDF在隔离库中生成和下载，不写正式网站。

## 来源入口实查与限度

本轮实际打开Physical Intelligence、Agility Robotics、CoreWeave、Nebius、Azure及AGIBOT六个入口。前三处更新到可达的正式入口：`pi.website/blog`、Agility的`resources`及CoreWeave的`newsroom`。CoreWeave列表含模板占位，后续逐期须检索并打开具体原文；不能将首页可达等同完整覆盖。其余入口为研究计划中的候选，本轮未声称30个入口已全量取材，也未将样刊内容重新认证为今日新闻。

## 交付与待上线项

本批只完成本地开发验证。尚未部署、推送标签或创建Release；正式数据库、生产配置和定时任务提示未改变。未来部署时，先核对服务端支持 `layout_version=2`，再同步 `fieldtofit-gpt` 为九栏及新版证据规则，保持原时刻和独立私密选题任务。真实自然日的来源覆盖、三市场行情和新刊回读须按日留证，不能由本地合成测试替代。
