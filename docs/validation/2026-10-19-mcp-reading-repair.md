# MCP兼容读取与接入诊断修复验收 · 2026-10-19

所有者明确要求修复三项问题，保持现有MCP兼容，先更新项目总览，再开发验证，通过后更新部署。方案先登记于[REQ-8-6／11／12](../../FieldToFit-PM.md#mcp-compatible-reading-repair)，按v1.12.0之后既有能力的兼容修复交付v1.12.1；无新模块、主要用户流程重构、数据库迁移或公共协议破坏。

## 修复内容

- `curated_news/watch/maps`新增可选summary／chunk。旧地址、19项精选／28项兼容／1项专题工具、原参数及默认完整返回保持；full也是旧结果。摘要默认5、最多10项，条目UTF-8 JSON预算10000字节；完整JSON片段默认4000、最多6000个Unicode字符，并受转义后10000字节预算约束。片段可能更短，按offset拼接、解析并核对SHA-256，直到has_more=false。
- 每次先按当前公开权限读取，游标绑定工具、查询、语言、页大小与内容哈希。内容改变时明确要求重读；旧游标不授予权限，也不保存旧正文。摘要有节选标识和精确reading，不能当全文或全部出处。
- stdio保留TLS校验及原环境变量，默认CA为空时可用已安装certifi；显式SSL_CERT_FILE／SSL_CERT_DIR不可被回退覆盖。区分证书、DNS、超时、HTTP和无效响应，不回显原异常／令牌；stdout只包含JSON-RPC，通知不伪造响应。
- 网页真实执行initialize、initialized通知、1项公开摘要读取，45秒整体超时；显示阶段、耗时及可理解错误，初始化成功不再等于读取通过。双语四客户端七路径、初始HTML、复制提问及排错说明共同更新。

旧客户端省略新参数仍可能取得大结果，这是保留旧契约的明确边界。新工具说明及接入提问优先引导有限摘要和所需条目的分段读取。其他工具保持原有limit、字符预算和同步游标。
