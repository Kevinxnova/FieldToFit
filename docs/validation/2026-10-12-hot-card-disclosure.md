# 热点信息卡按需展开验收

日期：2026-10-12（Asia/Shanghai），源码批次v1.8.40，对应[REQ-6-22](../../FieldToFit-PM.md#hot-information-cards-plan)。所有者要求默认隐藏人群和条件、悬停时显示，卡片略宽，并取消旋转。本地验证时尚未部署；2026-10-12完成代码部署，2026-10-13按明确授权发布首批三张卡片，正式结果见下文。

## 已实现

- 首页预览默认隐藏「对谁有用 · 本站判断」和「先看条件」，鼠标移入对应卡片或键盘聚焦时展开，离开后收起。Escape可收起；触屏使用明确的展开／收起按钮，按钮至少44px高，展开状态和内容关联同步给辅助技术。显式展开后保留，直到操作收起。
- 卡片平放，取消全部卡面旋转，保留符合动态效果偏好时的悬停上浮、放大与反光。减少动态效果仍能展开内容；触屏不依赖悬停。
- 三列间距改为12–16px，利用两侧各18px的留白，桌面目录170px／间距24px，增加实际卡宽；单列最大宽度由520px增加至560px。窄屏不使用两侧扩展。单张展开不会拉高相邻卡片。
- 官方证据、详情链接、待更新提示始终可见；完整详情、人工PNG、内容审核、日期及接口不变，无新增依赖或数据库迁移。

## 实际验证

环境为 `tests/browser/hot-cards_server.py` 提供的本地临时SQLite站点，本机Chrome无头浏览器及用户当前应用内浏览器。地址 `http://127.0.0.1:18062`。

1. `tests/browser/hot-cards-motion.cjs`：**117项交互检查通过，14张截图，页面脚本错误0**。中文／英文 × 浅／深色验证默认收起、无旋转、悬停展开、放大与反光、移开收起、相邻卡片高度不变、来源与内容对应及详情往返。
2. 键盘聚焦自动展开、Escape收起、按钮Enter切换、ARIA状态与内容一致均通过；减少动态效果时仍能查看展开信息。
3. 882px三张卡片逐张悬停，只展开对应卡片；1024px三列和目录抽屉跳转通过。1024／768／390／320px触屏下，中英文默认收起，按钮可以反复展开／收起，详情可达；页面无横向溢出，相关按钮／链接至少44px。
4. 320px加长文案和待更正提示仍可读，维护提示没有随人群与条件隐藏。
5. 应用内浏览器当前1224px窗口：三张卡片约243px宽、默认460px高，全部无旋转、额外信息隐藏、页面无横向溢出。聚焦第一张后只有第一张展开至约675px，另外两张仍约460px。人工查看默认截图与浅色展开截图确认内容和层级；局部自动截图的左右边缘取景不等同于页面裁切。
6. `npm --prefix frontend run build`类型检查与生产构建通过，128个模块，保留既有主包超过500kB提示。
7. `release_metadata.py --write`同步完成，无参数复核通过；`check_repository.py`核对v1.8.40、154文档、1272本地链接、315相对导入、23主REQ／156子REQ，错误0。`git diff --check`通过。

原始结果与截图保存在忽略目录 `output/operations/hot-cards/disclosure/`，包含 `result.json`、`current-window.jpg` 和中英／主题／触屏截图。上述本地展示批次未重复执行后端或分享图片回归；发布前已补跑下述79项回归。既有完整流程证据见[热点信息卡验收](2026-10-12-hot-information-cards.md)。
