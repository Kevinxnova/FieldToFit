# 首页四篇精选报告轮换验收

所有者在对齐首页四篇、发布成功后替换最早一篇、完整索引保留及同源规则后，明确要求先完善总览REQ和方案，再开发验证。对应[REQ-22-8](../../FieldToFit-PM.md#report-homepage-rotation-plan)。本批为既有模块兼容patch v1.10.3；最初完成本地开发验证；所有者随后明确“去更新并部署”，本页接续记录同一批次的正式结果。

## 方案与实现

先登记唯一PM总览、新REQ-22-8、细化方案和指南，再开发。初始只读核对：正式v1.10.2有九篇报告，交互首页上限四篇，直读首页正文仍列九篇，完整索引按原报告活跃日期排序，三者规则不一致。

后端report_selection提供固定四篇名单与统一上站排序；新闻、阅读摘要、报告完整索引和MCP返回同一名单，前端不再自行按普通updated_at排序。全部索引保留所有报告，30日分类仍使用原报告日期。首页和索引的直读日期使用北京时间，time属性保留真实机器时间。

首次纳入的报告在成功发布时记录服务器report_selected_at；已有稿的新原报告或新实质修订可再次置前。普通修字、图注／链接、核对、版本标签或重复同一修订不置顶。旧稿回退真实首次上站，无真实日期留空并排后，不使用来源／导入日期补造。新增读取信息会更新摘要revision，不创造公开发布历史或刷新旧日期。复用原集合JSON，无新表／迁移或读取时数据库写入。

成功发布后才返回report_rotation前后名单、进入、离开与仍在完整索引的条目；失败事务回滚，保存／预览不改变公开内容。回执丢失需先重读公开状态，不以网络异常推断事务未提交。完整内容、模型榜单、既有审核／双语保护及稳定slug保持。
