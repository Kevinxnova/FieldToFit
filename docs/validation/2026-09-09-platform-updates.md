## 行为检查

测试覆盖隔离 SQLite 和真实 HTTP 请求，未使用外部生成服务或用户密钥。核心检查包括：

- 翻页途中插入新对象、更新原对象：原快照成员与版本不变；重新检索可见新内容。
- 快照中的对象撤回：同一位置只返回 ID/修订及不可用状态，不丢失后续位置，不重新公开正文。
- 新增、待复核、重新发布、撤回：事件分别可见；对象显式重新送审和归并也产生退选通知；撤销归并不会自动恢复精选。
- 变化翻页期间新撤回留到下一窗口；完成检查点可以建立新窗口；无新内容明确返回空列表。
- 查询范围/页大小不匹配、游标错误/过期、超出本库水位均有明确错误；MCP 保留结构化错误代码。
- 未发布草稿不能通过公开期次接口读取；私有审核备注不进入期次正文或变化事件。
- 草稿编辑和来源修订使旧审核令牌失效；版本错误或无原句不能发布；出版记录和当前指针失败时一起回滚。
- 旧期次可回看固定修订，来源变更提示待复核，材料缺失/撤回遮蔽条目；整期撤回后不能再打开此前正文。
- 只有每日检查时间变化时，不产生新概览修订、不刷新公开日期；重复发布同一内容不创建重复记录。

最终测试、构建及仓库检查结果在文末记录。真实源材料的首尾续读继续沿用[基础验证](2026-09-09-platform-foundation.md)。
