# 2026-10-11 · 私密核对差异处置与历史

范围：REQ-19-2／REQ-19-3、REQ-10-1；所有者要求先定具体方案、开发并验证。方案登记在唯一[项目总览](../../FieldToFit-PM.md#req-19)。源码批次v1.8.24，正式网站最近已验仍为v1.8.23；本批未部署、未修改生产数据库或发布网站内容。

## 实际实现

- 每项差异支持不采纳、证据已撤回与手动恢复。关闭必须有理由与复查条件；恢复必填理由并保留原条件。网络失败不自动当撤回。
- 一张私密追加事件表保存原字段前后值、引文与偏移、来源URL／哈希／实际日期／版本、关联尝试、处理时间、理由、复查条件及处理版本；历史核对尝试不改写。旧差异从原记录派生身份，无虚构过去处置。
- 相同定位证据跨重试／日期抑制；新引文、版本、日期或建议值经实际核对后进入待办。当前旧值、整页哈希或引文偏移改变不解除旧决定。较新证据替代、当前已采纳该值或字段已不存在时拒绝恢复旧项。
- 当前跨日待办与日检查结果分开；处置本身不变更当天四类检查结果和完成数。更新提案只取待办，准备、继续与关联草稿前重新验证；旧版同类提案也识别，原用户决定历史保留。
- 管理员认证、实际当日、最新尝试、已审基线与处理版本共同约束写入，远端沿既有原子guard。新表由维护升级幂等建立并进入私密备份，缺表时显式提示升级。
