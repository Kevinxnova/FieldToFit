# 管理资料与运行状态（当前 beta.2）

当前精选发布和新页面请先看[平台使用指南](platform.md)。以下保留来源及旧工作流的维护说明。

以下表格描述当前可用后台。新目标是维护精选对象、原始材料和双端发布，完整的精选门槛、概览审核、发布预览和回退方案仍待适配，见 [REQ-O-01](../product/requirements/operations.md#req-o-01)。后台服务于维护者，不是给普通用户代做任务的第三个主页面。

`/admin` 面向 FieldToFit 的维护者。它与公开账户独立；当前公开注册和登录仍关闭。

在服务端配置 `ADMIN_PASSWORD` 后，通过管理页面登录。密码在当前浏览器会话内用于管理请求；退出会移除该会话中的管理凭证。不要在共享浏览器中保留登录状态。

| 页面 | 用途 | 当前边界 |
| --- | --- | --- |
| 资料审核 | 查找资料，编辑名称、摘要、分类、状态及有来源的事实 | 支持状态/事项过滤及分页；保存需要修改依据 |
| 来源配置 | 添加、编辑、启停来源，调整参数，重试或补采 | 周期固定 1 天；高级参数仍使用 JSON |
| 处理进度 | 查看原文/整理队列、积压、等待天数、P50/P95 延迟及运行记录，继续处理 | 操作可能访问外部来源或已配置模型 |
| 生成模型 | 配置服务地址、模型、凭证变量名、协议并测试 | 密钥保存在服务端；未配置时返回明确错误 |
| 归并与分歧 | 人工处理重复对象和事实分歧，维护关系 | 候选界面可选择主记录，核对原文并填写依据后归并；仅扫描最近 500 条事件 |
| 需求反馈 | 跟进缺失、纠错、任务反馈及处理状态 | 反馈条数不等于复用；新目标改为理解、取材和纠错闭环 |

“原策展后台”指向 `/admin/curation`，用于旧 tools、人工推荐和 Newsletter 流程。代码已独立到 `frontend/src/legacy/`，功能和接口仍保留。发送 Newsletter 是对外发送操作，不能把它当作普通的本地浏览验收。

已有本地验收覆盖登录、资料修正/恢复、来源保存、队列查看、缺少模型凭证提示和退出；未覆盖每一种生产管理动作。详情见 [验证索引](../validation/README.md)。
